# Step 0 效果对照与基线样本页

本目录提供 **Portrait Spine Studio** 的 Step 0 离线效果对照页，用于在正式拆件和绑骨前统一动作幅值、循环节奏与验收硬门禁标准。

## 打开方式

- `index.html` 为单文件、零外部依赖页面，直接用现代浏览器双击打开即可离线运行，无需启动构建工具或本地服务器。
- 顶部控制栏支持播放/暂停、归零至 `0.00s`、`0.5x / 1.0x` 倍速切换、`Gain` 倍率同步切换、画布背景切换（深灰 / 浅灰 / 棋盘格）以及骨架 / IK 叠加开关。

## 演示内容与标定基线

1. **三类核心角色预设并排对照**（统一 `8.0s` 无缝循环，主摆动 `k=1 / 8s`，呼吸 `k=2 / 4s`，严格首尾归零）：
   - **敏捷全身（艾瑞卡基线 / Erika v2）**：8s 重心与胸廓摆动、4s 呼吸起伏、双脚与左手 2-bone IK 钉死、发束/飘带链式相位滞后（`+0.35s/节`，振幅递推 `1.35x`），以及偶发耳部 C1 抽动（右耳 `2.9s / 12°`、左耳 `6.1s / 9°`）。
   - **重装持械全身（雷恩基线 / Rain）**：沉稳躯干摆动与头部反稳定、双腿 + 双手握持刚体大剑（`weapon_ctrl`）4 组 2-bone IK、毛领（`1.65x` 递推）与 4 节腰带飘带（`1.30x` 递推）大滞后跟随。
   - **半身无脚（胸像立绘）**：底边腰胯硬锚定（`ty ≤ 0.5px` 零露底）、胸廓呼吸微摆、头部反稳定抑制视线漂移与多节发丝飘动。

2. **`gain` 倍率同步对照（`0.7x / 1.0x / 1.3x / 1.5x`）**：
   - 实时计算各预设核心通道的当前位移与整周期 p2p 位移，对比标定参考区间；在 `0.7x`（偏弱）或 `1.3x / 1.5x`（压测过幅）时触发 `SOFT WARN`。

3. **硬门禁反例对照区（PASS vs FAIL）**：
   - `no_holes`：底层 Amodal 补全不足导致关节处撕裂露黑洞 vs 补全 ≥32px 全程零破洞。
   - `anchor_stability`：未钉脚踝 IK 导致脚底左右滑步（`> 1.5px`）vs 2-bone IK 稳态钉死（`0.00px`）。
   - `setup_identity`：未扣除 `t=0` 初相导致 `0s / 8s` 循环跳帧 vs 严格 `f(0) = f(8) = 0`。
   - `rest_diff`：静止帧（Frame 0）与原画逐像素差值热力图与 `maxRGBA ≤ 2` 门禁标准。
